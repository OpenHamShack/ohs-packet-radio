# Libraries the Packet Radio AppImage leaves to the host (shack-app.toml
# [linux] host_libs), the same list as QO-100 NB's and Radio's in
# openhamshack-nb: the core C, graphics and font stack the host's display
# server and drivers must match. Not the xcb-util family (libxcb-cursor,
# -icccm, -util, -image, -keysyms, -render-util, -xkb, libxkbcommon-x11),
# which Qt 6's xcb plugin needs and many hosts lack: those are bundled
# from the build image. So is libjack, which the bundled PortAudio links
# and a desktop without JACK lacks; ALSA is the host's, as its plugins and
# configuration are.
