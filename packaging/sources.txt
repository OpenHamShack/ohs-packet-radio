# The Corresponding Source for the third-party GPL and LGPL code inside
# Packet Radio's installers, one tarball per line, in the shared source
# site's manifest format (openhamshack-nb docs/source-site.md, served as
# https://openhamshack.com/source/HOW-TO-PUBLISH.txt). tools/publish.sh
# source publishes it as the manifest openhamshack-packet, with this
# release's own source (the app, and the ohs-libs libraries it carries),
# before any installer of the release goes up; its download pages and
# THIRD-PARTY.txt inside each installer point to
# https://openhamshack.com/source/#openhamshack-packet.
#
# Added for 0.2.0 (18/10/2026): no Packet Radio release before it offered
# this source, although 0.1.0-0.1.2 carried most of the same code.
#
# What it covers: everything GPL or LGPL in the Windows installer and the
# macOS .dmg, and in the Linux AppImage the Qt, PyQt6 and Python packages
# (the same pins). Permissively licensed parts (Python, numpy, Pillow,
# cryptography, PortAudio, PyAudio, pyserial, hidapi under its BSD option,
# libxml2, winpthreads, libhackrf itself) need no source offer and are
# named in THIRD-PARTY.txt only. The .deb carries none of this: it uses the
# distribution's packages. NOT yet covered: the Debian bookworm system
# libraries the AppImage carries (libstdc++, libreadline, libudev...);
# their source is Debian's, at https://snapshot.debian.org/, which
# THIRD-PARTY.txt says.
#
# Not listed, because they need no source offer: the notification voice
# clips (sounds/*.wav, 0.3.0), rendered once with Piper's en_GB-cori-high
# voice, whose model card gives its dataset's licence as public domain
# (THIRD-PARTY.txt; tools/render-voice.sh makes them again). Neither
# Piper (MIT) nor the voice model is shipped.
#
# Not listed either, because they are inside this release's own source
# tarballs (the app's and the ohs-libs one): code ported or vendored from
# elsewhere from 0.3.0 - sgp4 2.27 (MIT, shack_packet_app/sat/_sgp4 with
# its LICENSE), wl2k-go's LZHUF (MIT, shack_packet.lzhuf) and YAPP from
# F6FBB's yapp.c (GPL-2.0-or-later, shack_packet.yapp). THIRD-PARTY.txt
# names each.
#
# A tarball another project already lists is the same name and SHA-256
# here (libiio, libusb 1.0.24/1.0.29, libserialport, hackrf, paramiko):
# the site stores each once. Every hash below was taken from a download
# of the URL on 18/10/2026 and, for those already on the site, matches
# the site's SHA256SUMS.
#
# Keep this list exactly what the NEXT installers to be published carry:
# change a pin in a build script, change its line here in the same commit.
